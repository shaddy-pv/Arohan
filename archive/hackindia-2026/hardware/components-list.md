# Hardware Components List

To build the AROHHAN IoT node and autonomous rover, the following hardware components are required:

## IoT Sensor Node
- **Microcontroller**: ESP32 Development Board (Wi-Fi/Bluetooth enabled)
- **Gas Sensor**: MQ-2 or MQ-135 (Methane, Smoke, CO)
- **Temperature & Humidity**: DHT11 or DHT22
- **Flame Sensor**: IR Flame Detection Module
- **Motion Sensor**: HC-SR501 PIR Motion Sensor
- **Power Supply**: 18650 Li-ion Battery with TP4056 Charging Module
- **Miscellaneous**: Breadboard, jumper wires, resistors.

## Autonomous Rover
- **Microcontroller**: Arduino Uno or Mega
- **Motor Driver**: L298N Motor Driver Module
- **Chassis**: 4WD Smart Car Robot Chassis
- **Motors**: 4x DC Gear Motors
- **Obstacle Avoidance**: HC-SR04 Ultrasonic Sensors (x3)
- **Vision (Optional)**: ESP32-CAM for live video feed
- **Power Supply**: 11.1V LiPo Battery
