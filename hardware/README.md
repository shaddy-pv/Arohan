# Hardware

This directory contains all physical hardware code for the AROHAN system — rover firmware and ESP32-CAM firmware.

---

## 📂 Structure

```
hardware/
├── rover/          → Arduino firmware + face recognition server for the autonomous rover
└── esp32cam/       → ESP32-CAM firmware (camera streaming & capture)
```

---

## 🤖 Rover (`rover/`)

The autonomous rover is built on an Arduino-compatible microcontroller and communicates over WiFi.

| File | Description |
|---|---|
| `rover_firmware.ino` | Main Arduino sketch — motor control, sensor reading, WiFi |
| `face_recognition_server.py` | Standalone Flask server for face recognition on the rover |
| `train_faces.py` | Script to train the face recognition model from `known_faces/` |
| `face.html` | Standalone web UI for face recognition testing |
| `requirements.txt` | Python dependencies for the rover's face recognition server |
| `known_faces/` | Place training images here (gitignored — see `known_faces/.gitkeep`) |
| `trained_model/` | Trained model output (gitignored — generated by `train_faces.py`) |

### Setup

```bash
cd hardware/rover

# Install Python dependencies
pip install -r requirements.txt

# Train the face recognition model
# 1. Add face images to known_faces/<person_name>/
python train_faces.py

# Start the face recognition server
python face_recognition_server.py
```

Flash `rover_firmware.ino` to your Arduino board using the Arduino IDE.

## 📷 ESP32-CAM (`esp32cam/`)

| File | Description |
|---|---|
| `esp32cam.ino` | Firmware for the ESP32-CAM module — handles MJPEG streaming and JPEG capture |

### Setup

1. Open `esp32cam.ino` in Arduino IDE
2. Set your WiFi SSID and password in the sketch
3. Flash to an ESP32-CAM board (AI-Thinker model recommended)
4. The camera will be accessible at `http://<device-ip>:81`

---

## 🔌 Hardware Requirements

| Component | Purpose |
|---|---|
| ESP32-CAM (AI-Thinker) | Live camera streaming |
| Arduino Mega / ESP32 | Rover main controller |
| L298N Motor Driver | Drive motors |
| MQ-2 Sensor | LPG / smoke detection |
| MQ-135 Sensor | Air quality / gas detection |
| DHT11/DHT22 | Temperature & humidity |
| Flame sensor | Fire detection |
| PIR sensor | Motion detection |
| Ultrasonic (HC-SR04) | Obstacle avoidance |
